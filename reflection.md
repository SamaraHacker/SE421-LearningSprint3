Reflection:

Building this application helped deepen our understanding of the topic by providing a more visual element to the topics presented in class about algoirthmic complexity attacks. Since we used a similar example to the one in class, it was applicable to what we were learning and allowed us to go through the work ourselves. Additionally, it shows how various different inputs can lead to the same bucket, like how a hash table works, showing that an attack can do the same thing.

For building this application, we first worked at adding simple elements into the html file. These included the input text field, submit button, title, and finally the buckets. From there we then worked on the simple functionality of the app where we connected the input to the user to inserting a div element to the corresponding bucket. Finally, we ensured that a proper message appeared when worst case scenario complexity was reached, letting the user know that it occurred.
