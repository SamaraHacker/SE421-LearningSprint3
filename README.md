This app visually demonstrates an AC Attack, that being Hash Table DoS Attack. Enter the input for a given value, and the corresponding hash value will be filled next to the bucket it belongs too. The goal is to overfill one of the buckets causing worst case scenario complexity for the hash table. You will be given a notification once this occurs.

To run this app please open the file titled "index.html" in your preferred browser.
